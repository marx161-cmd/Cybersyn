# Notice

This is a public source dump of a personal phone-sensor control stack. Use it,
fork it, adapt it, or strip it for parts. Do not expect maintenance, support,
compatibility guarantees, issue response, or a stable roadmap from the original
author.

The stack was built around Android sensor events, MQTT, Linux `uinput`, Tasker,
Termux, and host-side accessibility workflows. The public version is source
only and intentionally avoids shipping private device state, APKs, or live host
configuration.
